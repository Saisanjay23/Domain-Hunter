Active storage

Where hunts, case notes, the watchlist and alerts are saved.

MongoDB connection

Use MongoDB instead of the local SQLite file, for example to share one history between analysts or keep it on a managed cluster. The connection is tested before anything is saved.

MONGODB_URI is set in the system environment. Change it there.

Copy existing data

Switching storage does not move old records. Copying is safe to repeat: hunts and case notes are updated by id, watched brands already present are skipped, and alerts are copied only into an empty destination. Watchlist webhook URLs are copied too, so protect the database like any credential store.

Platform notes
  • Shodan filters and FOFA icon_hash need a logged-in account. Censys links open the Censys Platform (CenQL).
  • MMH3 goes to FOFA and Shodan; MD5 to Censys (which hashes only the first 384 KB); SHA-256 to URLScan hash:, which matches any resource a scanned page loaded.
  • Logos are searched on URLScan only, since the other platforms index favicons only.
  • Platforms only return what their crawlers have indexed: zero results for a new or private site is normal.
